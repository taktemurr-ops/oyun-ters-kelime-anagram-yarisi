# Anagram Yarışı · Anagram Race

Karışık harfleri süre bitmeden çöz!

Her turda bir kelimenin harfleri karışık gelir. Harflere doğru sırayla dokun; aynı harflerle kurulan başka gerçek kelimeler de kabul edilir. Toplam süre bitmeden bütün kelimeleri çöz.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
